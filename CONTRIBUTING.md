# Contributing to Edge Reverse Caching Proxy

Thank you for your interest in contributing to **Edge Reverse Caching Proxy**! We welcome bug reports, design suggestions, and performance optimizations.

## Code of Conduct
This project follows the [Contributor Covenant 2.1](CODE_OF_CONDUCT.md). By participating, you agree to uphold this code.

## Development Workflow
1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit Guidelines**: Use clear semantic commit messages:
   - `feat:` new capabilities or route additions
   - `fix:` bug fixes or error handling corrections
   - `docs:` documentation improvements or diagrams
   - `perf:` algorithmic optimizations or cache latency gains
4. **Submit a Pull Request**: Push your branch and open a PR against `main`. Provide a concise description of your changes and reference any related issues.
